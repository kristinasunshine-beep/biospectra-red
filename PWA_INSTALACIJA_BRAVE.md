# Instalacija BIOSPECTRA u Brave-u (Android)

1. Otvorite `https://kristinasunshine-beep.github.io/biospectra-red/` u običnoj Brave kartici.
2. U meniju izaberite **Install and Create shortcut**, pa dostupnu opciju instalacije.
3. Ako je stara prečica već na početnom ekranu, uklonite je pre nove instalacije.
4. Novi R32 ikonik biće preuzet po objavljivanju GitHub Pages izmenâ i osvežavanju sadržaja.

Narandžasta Brave oznaka može ostati kada Android napravi prečicu, a ne nezavisno instaliranu PWA aplikaciju. To je ponašanje browsera/launchera, ne deo BIOSPECTRA ikonica.
